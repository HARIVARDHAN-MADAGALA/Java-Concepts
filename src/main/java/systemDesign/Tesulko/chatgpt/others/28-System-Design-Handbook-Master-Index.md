# Interview Checklist

Before every system design interview:

-   Clarify functional requirements
-   Clarify non-functional requirements
-   Estimate scale
-   Draw high-level architecture
-   Design database
-   Add cache
-   Add load balancer
-   Add message queue
-   Discuss replication/sharding
-   Discuss fault tolerance
-   Discuss monitoring
-   Explain trade-offs

Congratulations! You have completed the core handbook. The next step is
practicing complete end-to-end system design questions.
