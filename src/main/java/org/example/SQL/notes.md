# Spring Boot JPA + MySQL Configuration

## Full Config Snippet

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/order_db?createDatabaseIfNotExist=true&useSSL=false&serverTimezone=UTC
    username: root
    password: root
    driver-class-name: com.mysql.cj.jdbc.Driver
  jpa:
    hibernate:
      ddl-auto: update
    show-sql: true
    properties:
      hibernate:
        format_sql: true
        dialect: org.hibernate.dialect.MySQLDialect
```

---

## 1. spring.datasource — Database Connection

### url
```
jdbc:mysql://localhost:3306/order_db?createDatabaseIfNotExist=true&useSSL=false&serverTimezone=UTC
```

| Part | Meaning |
|---|---|
| `jdbc:mysql://` | JDBC protocol for MySQL |
| `localhost` | DB host |
| `3306` | Default MySQL port |
| `order_db` | Database name |
| `createDatabaseIfNotExist=true` | Auto-creates DB if not exists |
| `useSSL=false` | Disables SSL warnings (dev only) |
| `serverTimezone=UTC` | Fixes timezone mismatch |

### username and password
```yaml
username: root
password: root
```
- Credentials to log into MySQL
- Never hardcode in production — use environment variables or Spring Config Server

### driver-class-name
```yaml
driver-class-name: com.mysql.cj.jdbc.Driver
```
- Fully qualified MySQL JDBC driver class
- `cj` = Connector/J (modern MySQL driver)
- Spring Boot auto-detects it, but explicit is clearer

---

## 2. spring.jpa — Hibernate & JPA Configuration

### hibernate.ddl-auto
```yaml
ddl-auto: update
```

| Value | Description |
|---|---|
| `none` | Do nothing (production default) |
| `create` | Drop and recreate tables on startup ❌ |
| `create-drop` | Same as create, drops on app stop |
| `update` | Auto-updates schema to match entities ✅ dev |
| `validate` | Only checks schema, throws if mismatched |

### show-sql
```yaml
show-sql: true
```
Prints SQL queries generated by Hibernate in console — useful for debugging.

```sql
select user0_.id, user0_.name from user user0_;
```

### format_sql
```yaml
format_sql: true
```
Beautifies printed SQL with indentation:

```sql
select
    user0_.id,
    user0_.name
from
    user user0_;
```

### dialect
```yaml
dialect: org.hibernate.dialect.MySQLDialect
```
Tells Hibernate which SQL flavor to use — each DB (MySQL, PostgreSQL, Oracle) has slight syntax differences.

---

## 3. Runtime Flow

1. Spring Boot reads datasource config → creates connection pool (HikariCP)
2. Connects to `order_db` using given credentials
3. Hibernate scans `@Entity` classes and compares with DB tables
4. Based on `ddl-auto` — creates/updates/validates tables
5. On repository calls → Hibernate translates to SQL (visible via `show-sql`)

> This YAML config connects Spring Boot to MySQL using JPA + Hibernate, controls schema updates via `ddl-auto`, and enables SQL logging for debugging.
