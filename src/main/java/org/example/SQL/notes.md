### 🔹 hibernate.ddl-auto

This tells Hibernate **how to handle database schema generation** (DDL = Data Definition Language).

ValueDescriptionnoneDo nothing (default in production).createDrop and recreate tables on every startup. ❌ Dangerous for prod.create-dropSame as create, but drops tables when app stops.update✅ Automatically updates schema to match entities (safe for dev).validateOnly checks schema — throws error if mismatched.

🧠 **Here:** update means if you add new fields to an Entity, Hibernate will alter the table automatically.

🧠 3️⃣ What Happens at Runtime (Step by Step)
---------------------------------------------

1️⃣ Spring Boot reads the datasource config and creates a **connection pool** (usually HikariCP).2️⃣ It connects to order\_db using the given credentials.3️⃣ Hibernate scans your **Entity classes** (@Entity) and compares them with database tables.4️⃣ Based on ddl-auto, it **creates/updates/validates** tables.5️⃣ During runtime, when you call a repository method, Hibernate translates your **JPQL / repository call** into **SQL** (you can see it because of show-sql: true).
